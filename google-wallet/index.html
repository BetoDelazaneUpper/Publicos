ARCHITECTURE

Segredo no servidor. Fluxo no browser.

O browser pede uma Save URL. O backend monta Class + Object, assina o JWT com RS256 e retorna apenas o link final. A chave privada nunca atravessa a fronteira do servidor.

01
Issuer

Crie ou use um Issuer no Google Wallet Business Console.

02
Service Account

Ative a Wallet API e autorize a Service Account no Issuer.

03
JWT

O backend assina o payload com a private key da Service Account.

04
Save URL

O usuário abre o link oficial e confirma o passe no Google Wallet.

LOCAL SETUP

Rodar em poucos minutos.

cd google-wallet/example
npm install
cp .env.example .env

# configure:
# GOOGLE_APPLICATION_CREDENTIALS
# GOOGLE_WALLET_ISSUER_ID

npm start
# http://localhost:8080
O exemplo público não contém Issuer real, chave privada, Client Secret, Service Account, token ou qualquer outro dado sensível.
